# MK2 Customs — FiveM Development Website

## Included
- `index.html` — full website
- `style.css` — responsive purple/neon styling
- `script.js` — mobile navigation, cursor glow and reveal animations
- `assets/mk2-banner.png` — the MK2 Customs banner you supplied

## Customize
Open `index.html` and replace:
- `your@email.com` with your real business email
- `https://discord.com/` with your real Discord invite/server link

You can also change the text in the Services, About and Contact sections.

## Run
No server is required for the basic site. Double-click `index.html` to preview it in a browser.

For hosting, upload the entire folder to your web host with the `assets` folder kept beside `index.html`.
